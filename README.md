# NeoArenaV1

Hyper Casual Battle Royale for Mobile Where players compete for Stable Coin.

## 🎮 About

Neo Arena V1 is a fast-paced, hyper-casual battle royale game designed for mobile platforms. Players compete in intense matches where up to 100 players battle in a shrinking arena, with the last player standing winning stable coin rewards.

## ✨ Features

- **Battle Royale Mechanics**: Up to 100 players per match
- **Shrinking Safe Zone**: Arena shrinks over time, forcing player encounters
- **Stable Coin Rewards**: Winners earn cryptocurrency rewards
- **Fast-Paced Matches**: 5-minute rounds for quick gaming sessions
- **Mobile-Optimized**: Designed for mobile gameplay

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Neepurna/NeoArenaV1.git

# Navigate to project directory
cd NeoArenaV1

# Install dependencies
npm install

# Run the game
npm start
```

### Running Tests

```bash
npm test
```

## 🎯 Game Mechanics

### Rewards
- 🥇 First Place: 100 Stable Coins
- 🥈 Second Place: 50 Stable Coins
- 🥉 Third Place: 25 Stable Coins
- 🎟️ Participation: 5 Stable Coins

### Match Settings
- **Duration**: 5 minutes
- **Arena Size**: 1000x1000 units
- **Max Players**: 100
- **Min Players**: 10
